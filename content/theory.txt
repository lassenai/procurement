회원 가입·업체 등록·개별 입찰자격의 구별|나라장터의 개인회원 가입은 이용자의 신원을 확인하는 단계이다. 경쟁입찰참가자격등록은 업체의 대표자, 업종, 제조·공급 물품, 입찰대리인 등을 등록하는 단계이다. 실제 입찰 참여 여부는 해당 공고의 자격요건과 기준일을 다시 대조해 판단한다.¶실무 순서는 본인 확인 → 소속업체 확인 또는 업체 등록신청 → 증빙 제출 → 심사·보완 → 승인 상태 확인 → 개별 공고 검토이다. 신청서를 전송한 상태와 승인되어 등록된 상태는 다르다.|업체 등록은 끝났지만 공고가 요구하는 면허가 없다면, 등록 사실만으로 참가자격이 충족되지는 않는다.|개인 인증, 업체 자격등록, 개별 공고 요건 충족을 구분하고 최종 승인 상태를 확인한다.|로그인 성공이나 등록신청 접수만을 참가자격 취득으로 쓰지 않는다.|경쟁입찰참가자격등록;개별 공고;승인 상태
제조물품과 공급물품·업종 등록|제조물품 등록은 해당 물품을 직접 생산하는 업체의 등록이고, 공급물품 등록은 해당 물품을 공급하는 업체의 등록이다. 제조 등록이 요구되는 공고에 공급 등록만 갖추고 참여할 수 있다고 단정하면 안 된다.¶공사·용역은 관계 법령에 따른 업종·면허·등록 요건을 확인한다. 공고의 업종코드와 등록증의 업종이 일치하는지, 공동수급이 허용되는지, 각 구성원의 자격을 어떻게 판단하는지도 함께 살핀다.|제조업체만 참가하도록 한 공고에서 판매대리점 계약서를 제시해도 직접 제조자격을 대신하는 것은 아니다.|대상물 유형 확인 → 제조·공급 또는 업종 요건 구분 → 등록정보와 면허·증빙 대조.|사업자등록증에 품목이 적혀 있다는 사실과 조달상 참가자격 충족은 별개이다.|제조물품;공급물품;업종·면허·등록
직접생산확인: 무엇을 증명하는가|직접생산확인은 명칭이나 판매권이 아니라 생산시설, 생산인력, 생산공정 등 제품별 기준을 충족하여 실제로 생산하는지를 확인하는 것이다. 중소기업자간 경쟁제품의 직접생산확인과 조달청 제조물품 등록 관련 확인은 적용 근거와 대상부터 구분한다.¶공고의 세부품명, 제조·직접생산 요구, 확인서 유효기간, 자격 판단 기준일을 대조한다. 공장 이전이나 생산시설 변경이 있으면 기존 증빙을 그대로 사용해도 되는지 확인하고 필요한 변경 절차를 진행한다.|확인서가 유효해도 공고의 세부품명과 확인서의 대상 제품이 다르면 충족 여부를 다시 판단해야 한다.|대상 제품과 적용 기준을 정하고 생산시설·인력·공정, 확인서 대상과 유효기간을 점검한다.|완제품을 사서 포장·납품하는 행위를 언제나 직접생산으로 인정한다고 쓰지 않는다.|생산시설;생산인력;생산공정;세부품명;유효기간
물품분류번호·세부품명번호·물품식별번호|물품분류번호는 물품의 종류를 나타내는 8자리 번호이다. 대·중·소·세 분류의 4단계를 각 2자리로 표현한다. 세부품명번호는 물품분류번호 8자리에 세분한 2자리를 더한 10자리 번호이다.¶물품식별번호는 제조업체·모델·특성 등으로 구별되는 개별 물품에 부여하는 8자리 번호이다. 물품목록번호는 물품분류번호와 물품식별번호로 구성된다. 같은 세부품명에 속해도 모델·규격이 다른 제품의 식별번호는 달라질 수 있다.|엘리베이터라는 종류의 분류와, 특정 제조업체의 특정 모델을 식별하는 것은 서로 다른 작업이다.|분류 8자리 = 종류 / 세부품명 10자리 = 세부 종류 / 식별 8자리 = 개별 제품.|8자리라는 이유만으로 물품분류번호와 물품식별번호를 같은 번호로 판단하지 않는다.|물품분류번호;세부품명번호;물품식별번호;물품목록번호
목록화 요청과 중복 등록 방지|목록화는 통일된 품명과 속성으로 물품을 설명하고 고유번호를 부여해 거래·재고·통계를 일관되게 관리하는 과정이다. 먼저 기존 품명과 제품이 등록되어 있는지 검색한다.¶적합한 세부품명이 없으면 품명 분류 요청 필요성을 검토하고, 세부품명은 있지만 해당 제품이 없으면 품목 등록에 필요한 제조업체명·모델명·규격·대표속성·증빙을 준비한다. 요청 후 보완·승인 결과와 부여 번호를 확인한다.|이미 등록된 동일 모델을 새 제품처럼 중복 신청하기보다, 기존 정보와 실제 규격이 일치하는지 먼저 확인한다.|기존 목록 검색 → 분류·품목 요청 구별 → 속성·규격·증빙 작성 → 심사·보완 → 승인 번호 확인.|목록화 완료 자체가 입찰참가자격이나 낙찰을 보장하지는 않는다.|목록화;고유번호;제조업체명·모델명·규격
대표자·입찰대리인·등록정보 변경|대표자·상호·주소·업종·제조공장·입찰대리인 등 실제 정보가 변경되면 관련 등록정보를 확인하고 필요한 변경등록을 한다. 법인등기, 사업자등록, 면허와 나라장터 정보의 불일치를 방치하지 않는 것이 핵심이다.¶입찰대리인은 정당한 위임과 재직 등 필요한 요건을 증명해야 한다. 담당자 퇴사 시에는 권한 회수와 대리인 변경, 인증수단 관리까지 연결한다. 변경 신청 후 승인·반영 여부를 확인해야 실제 제출 오류를 줄일 수 있다.|대표자가 바뀌었다면 새 대표자 정보의 증빙과 시스템 반영을 확인한 뒤 공고의 자격 기준에 맞춰 제출한다.|변경 사실 확인 → 공적 증빙 갱신 → 시스템 변경등록 → 승인 확인 → 대리권·제출 권한 점검.|다른 직원의 인증수단을 공유하는 것을 적법한 대리인 등록의 대안으로 쓰지 않는다.|변경등록;입찰대리인;승인·반영
공고별 제출서류 점검표 만들기|서류를 자격증빙, 실적·평가증빙, 기술·가격서류, 보증·서약서로 나누고 각각의 제출 주체·기한·형식·유효기간을 정리한다. 공동수급이라면 대표업체 제출분과 구성원별 제출분도 구별한다.¶공고 원문, 붙임, 정정공고를 함께 확인한다. 파일의 서명·날인, 누락 페이지, 금액 단위, 발급기관과 대상 업체를 확인하고 최종 접수증을 남긴다. 준비와 접수 완료를 별도의 확인 항목으로 둔다.|유효한 실적증명서라도 다른 법인의 실적이거나 공고상 인정 기간 밖이면 평가자료로 인정되는지 별도 검토해야 한다.|요구서류 목록화 → 대상·기간·형식 검토 → 정정사항 반영 → 제출·접수증 보관.|파일 업로드 화면만 보고 최종 전송과 접수 완료를 확인하지 않는 실수를 피한다.|자격증빙;유효기간;정정공고;접수증
참가자격 사례형 답안 작성|사례형은 결론부터 추측하기보다 요구 요건과 보유 자격을 나란히 비교한다. 판단 기준일, 등록 상태, 직접생산·면허 증빙, 제한 여부를 사실관계로 적고 부족한 항목을 특정한다.¶답안은 요건 → 사실 대조 → 참가 가능 여부 또는 추가 확인 → 보완 조치 순으로 쓴다. 자료가 부족하면 어떤 증빙과 기준을 확인해야 하는지 명시한다. 근거 없는 단정 대신 판단에 필요한 조건을 적는다.|공고는 제조 등록과 유효한 직접생산확인서를 요구하는데 업체는 공급 등록만 보유했다면, 부족한 두 요건을 각각 적어야 한다.|요구 자격을 특정하고 실제 등록·증빙과 비교하여 결론 및 보완 절차를 제시한다.|문제에 없는 자격이나 보완 가능 기간을 임의로 가정하지 않는다.|요건 → 사실 대조;판단 기준일;보완 조치

수요정보 수집과 시장·환경 분석|공급계획은 발주계획, 과거 계약실적, 수요기관의 사업·예산, 정책 변화, 경쟁업체와 공급망 정보를 함께 분석해 수립한다. 기간·기관·품목·지역별로 자료를 분류하고 출처·추출일을 남긴다.¶발주계획은 미래 수요의 단서이고 계약실적은 과거 거래의 결과이다. 계획만을 확정 매출로 보거나 일회성 대형계약을 반복 수요로 보는 오류를 피한다. SWOT에서는 강점·약점은 내부 역량, 기회·위협은 외부 환경으로 구분한다.|기관의 구매량 증가가 신규 청사 개소 때문이라면 다음 해에도 같은 규모가 반복된다고 예측하기 어렵다.|자료 수집 → 분류·정제 → 변화 원인 분석 → 수요기관·품목 선정 → 공급계획 반영.|발주계획과 실제 공고·계약실적을 같은 확정 정보로 취급하지 않는다.|발주계획;계약실적;SWOT
